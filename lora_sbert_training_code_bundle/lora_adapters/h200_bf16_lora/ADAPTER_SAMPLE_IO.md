# 어댑터별 실제 입력/출력 샘플

이 문서는 실제 학습 JSONL에서 추출한 샘플이다. 입력은 `system message`와 `user message`, 출력은 `assistant message`에 해당한다.

샘플은 각 어댑터에서 `부족` 라벨 row 중 가장 짧은 실제 학습 row를 선택했다. 본문은 자르지 않았다.

## 신규성 어댑터 샘플

### 메타데이터

```json
{
  "dataset_id": "case_19932",
  "task": "novelty",
  "class_label": "거절-신규성 부족",
  "decision_label": "거절",
  "novelty_label": "부족",
  "inventive_step_label": "판정제외",
  "target_uid": "target:rejected_record:09932",
  "prior_uids": [
    "combined:86879",
    "combined:18684"
  ],
  "prior_match_ranks": [
    1,
    2
  ],
  "prior_match_scores": [
    0.481945,
    0.269183
  ]
}
```

### 입력 1: system message

```text
당신은 한국 특허 심사 보조 모델입니다. 심사대상 문헌과 선행문헌 D1,D2의 발명의 명칭, 초록, 청구항만 근거로 판단합니다. 허용된 라벨만 사용하고 JSON 객체 하나만 출력합니다.
```

## 진보성 어댑터 샘플
